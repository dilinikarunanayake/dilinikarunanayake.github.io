DILINI PORTFOLIO WEBSITE - GITHUB PAGES

Files in this folder:
- index.html: the website homepage
- portfolio.pdf: the downloadable professional portfolio
- assets/: award and Business Review/team event photos used by the website

To publish:
1. Create a new GitHub repository named dilinikarunanayake.github.io (or use a suitable existing repository).
2. Upload the contents of this folder to the top level of the repository. Include index.html, portfolio.pdf, and the complete assets folder. Keep the assets folder in place so the photos appear on the site.
3. Commit the files.
4. Open repository Settings, then Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and the root folder, then Save.
6. GitHub Pages will publish the site at https://dilinikarunanayake.github.io/ after the build completes.

Before publishing, review the content and add a professional email address or LinkedIn link if you want recruiters to contact you through the site. GitHub Pages websites are public.
