# Dilini Karunanayake — Portfolio

A responsive, one-page professional portfolio for sharing with UK recruiters. The design uses a deep navy navigation bar, large photo-led hero and bold white headline, taking visual direction from Vora Global Solutions while keeping Dilini’s own CV, photos, awards and identity. It includes a downloadable CV and a direct email button.

## Publish with GitHub Pages

1. Sign in to GitHub as **dilinikarunanayake**.
2. Create a new **public** repository named exactly `dilinikarunanayake.github.io`.
3. Unzip this folder on your computer. Open the unzipped `dilini-portfolio-site` folder and select **all of its contents** (`index.html`, `README.md`, and `assets`).
4. In the new GitHub repository, choose **Add file → Upload files**. Drag the selected contents into the upload area. Make sure `index.html` and the `assets` folder are at the top level of the repository.
5. Select **Commit changes**.
6. Open the repository’s **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
7. After GitHub finishes publishing, visit `https://dilinikarunanayake.github.io/`.

It may take a few minutes for the first publication to appear. You can update the portfolio later by editing `index.html` or replacing the files in the repository.

## Before sharing

This portfolio displays the phone number and email address from the supplied CV. Review those details and the CV PDF before making the repository public. The LinkedIn URL was not included in the CV, so no LinkedIn button has been added. You can add it in the contact section of `index.html` once you have the exact profile link. The **Email Dilini** button uses a `mailto:` link to the CV email address and opens the visitor’s default email app with a subject line; it does not send a message automatically.
